# Lecture du pilote : raccord local fermé par défaut

Ce lot ajoute uniquement le GET de dossier et le lien interne vers chaque dossier consultable. Aucun bouton de départ, versement, claim, droit modifié, menu global ni lien depuis Premiers pas. Les dossiers historiques possédés restent navigables. Tant que la projection des reçus de convoi n’est pas reliée, le vieux texte de devis « n’a pas été versé » est délibérément absent de cette page, même pour une victoire historique.

Seul le kernel Symfony dev importe cette route et son contrôleur. En dev, les valeurs absentes, fausses ou mal formées laissent le contrôleur fermé, avec un 404 neutre et privé sans cache. L’opt-in, s’il est un jour explicitement autorisé sur une base locale isolée, choisit côté serveur PIRATE_PILOT_LOCAL_ENABLED (valeur exacte 1) et PIRATE_PILOT_LOCAL_OMEGA_ID (décimal canonique strictement positif, ID d’Omega dans cette seule base). Le contrôleur ne lit pas ces paramètres dans la requête et ne choisit pas d’instance ou de contexte à partir d’un hôte ou d’un numéro de mission. On retire l’opt-in pour fermer immédiatement la lecture ; aucun état de jeu n’est effacé. Les deux paramètres sont ignorés en dehors du kernel dev.

La route est soumise au firewall authentifié existant : une session manquante suit la redirection d’authentification habituelle ; une route inexistante hors dev reçoit le 404 du framework sans traitement spécifique. Après ce firewall, l’adaptateur refuse les réglages désactivés avant toute lecture, puis revalide compte/participation actuelle et Omega d’après la base. Les lectures de détail appliquent encore le scope propriétaire. Aucune utilisation d’UniverseContext, aucun marquage de présence ou script global ; seuls la feuille de style locale et les liens de lecture sont utilisés. Réponses de cette page et refus du contrôleur : Cache-Control private, no-store.

Vérification hors base : debug:router Symfony natif avec variables absentes et forcées dans dev, prod, alpha et test, Twig/YAML/conteneur, loader et refus synthétiques. L’ouverture authentifiée réelle et ses cas historiques nécessitent des comptes de test sur une instance dev locale séparée ; aucun pilote n’a été activé ici.
