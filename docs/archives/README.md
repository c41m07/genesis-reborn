## Principes de conservation

Aucun Markdown n’est chargé dynamiquement à partir de cette liste. Le wiki lit
uniquement REGLES, DECISIONS et wiki.json, qui restent en place. Les décisions
initiales, QCM, progression, matrice Work, validation UI et audit d’illustrations
sont conservés. Les PDF, CSV, images et SVG ne sont pas supprimés par ce lot.
Les 150 libellés et descriptions de CATALOGUE_LABELS.md proviennent du CSV.
Sa colonne supplémentaire « utilité dans le jeu » est transférée dans le CSV :
les cinq colonnes existantes restent identiques, pour les 150 entrées.
L’ancien tableau de coûts des vaisseaux est supplanté par la grille commune
incluant l’hydrogène T3. Aucun coût ni prérequis n’est modifié.


## Vérifications de cette consolidation — 7 novembre 2026

- 22 Markdown restants ; les liens locaux sont vérifiés dans l’arborescence finale.
- REGLES, DECISIONS et les notes Alpha conservent leur texte hors destinations de références.
- Les sources PHP/JS, valeurs de catalogue, migrations et fichiers .env sont inchangés.
- Le scénario navigateur wiki réussit : guide, deux sources, droits, clavier,
  trois largeurs et deux thèmes (1 scénario, 29,3 secondes).
- Les 150 lignes du CSV conservent leurs cinq colonnes et récupèrent l’utilité unique.
- Le contrôle du diff est effectué après ces modifications.

Les suites applicatives complètes du lot précédent ne sont pas relancées pour
ce changement documentaire ; seul le wiki consomme les Markdown modifiés.
Après ces vérifications, le propriétaire autorise le commit et l’envoi du lot
vers dev. Aucune migration, modification des secrets ni opération sur le serveur
Alpha n’est effectuée.
