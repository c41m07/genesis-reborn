# Inventaire UI/UX — Genesis Reborn

## Méthode et limites

Inventaire initial établi depuis `debug:router --show-controllers`, les contrôleurs et les templates présents dans le dépôt le 5 novembre 2026. Les endpoints POST/API/techniques sont rattachés à leur écran parent, pas comptés comme pages autonomes. Les routes dynamiques représentent un gabarit de page, pas chaque enregistrement. Les routes `health`, API et logout ne sont pas des écrans UI.

Les droits indiqués sont à confirmer avec `security.yaml` et les attributs des contrôleurs avant les lots d’implémentation. L’application et ses bases Docker sont démarrées, mais l’accès navigateur avec comptes joueur et administrateur n’a pas encore été vérifié. Aucune page n’est considérée auditée ou validée visuellement à cette étape.

### Endpoints rattachés à des écrans

Les routes POST qui complètent les pages ci-dessus couvrent renommage/ressources/files de construction/annulation, actions de flotte (mission rapide, estimation, orbite, envoi), diplomatie, messagerie, boosts, préférences/profil, jonction d’univers, ainsi que rôles, suspension, modération, réglages/création/suppression/planification d’univers, catalogue, événements, retours et notes côté administration. Elles seront auditées dans le contexte de leur formulaire ou interaction parent.
